# Release — Orbit Fluid 1.0

- Preserved old 5× frame atlas and 3D sculpt pages for comparison.
- Replaced optical-flow/morphing playback with a four-part, continuously interpolated pose rig.
- Added velocity-preserving spring state machine; 28 modes and 5 chained workflows.
- Added integrated face-display system (animated eyes, scanning, caution, complete, error, processing).
- Added playback speed, hover, expressiveness, reduced motion, PNG and video capture.
- Added responsive desktop/mobile Studio UI, dedicated offline app shell and actual motion preview.
- Separated prototype library from new studio; no browser data migration or remote AI.
